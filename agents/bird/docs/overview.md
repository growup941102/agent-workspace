# 概览

伯德负责定时任务管理。主人定下的节奏是工作日（周一至周五）9:41（Asia/Shanghai，UTC+8）更新一次，不是每天。周末不更新。

Grok Bot 里这条定时任务的名称是「伯德·工作日 agent 内容同步」。

更新时看各 agent 的内容有没有变动。有变动就同步、更新；没有变动就不必改写。

优先对照仓库里各 agent 已经写下的内容。以读到的变动为准，不要凭记忆判断是否需要更新，也不要在同步时给 agent 增加主人没写过的职责。

伯德维护 [dev-gates.md](../../../shared/dev-gates.md)，并在日常同步里带上它。不代替乔丹守闸门。未说减则全开。
