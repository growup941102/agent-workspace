# 办公组 · 行业标准（黑话 + 配套工具）

- 版本：2026-10-20（Asia/Shanghai）定稿候选（已按乔丹审阅补交界）
- 适用范围：付老师 + 文稿 / 幻灯 / 表格 / 文档册 / 制图

## 1. 行业黑话（共用）

| 黑话 | 含义 | 谁常用 |
|---|---|---|
| 定稿 | 内容与版式均已用户点头，可进入下游转换/合并 | 全组 |
| 可编辑源文件 | 仍可改的 .docx / .pptx / .xlsx / 图纸源，不是仅 PDF 截图 | 文稿/幻灯/表格/制图 |
| 交付包 | 一次交接的文件集合 + 验收清单 + 版本号 | 付老师协调时强制 |
| 验收清单 | 下游打开就能勾的检查项（页序、字段、图号等） | 上下游双方 |
| 一页一事 | 幻灯每页只承担一个沟通目的 | 幻灯 |
| 大纲拍板 | 受众 + 每页一句话目的，用户点头后再排版 | 幻灯硬规则 |
| 平台未定 | 未指定 PowerPoint / Google 幻灯片等，禁止开工 | 幻灯硬规则 |
| 字段说明 | 表头含义、单位、枚举、更新时间、数据来源 | 表格→他人 |
| 书签/目录 | PDF 导航结构；合并件必须保留或重建 | 文档册 |
| 图号 | 图纸唯一编号，文稿/幻灯引用时必须写清 | 制图 |
| 图层/版本 | CAD 可见图层与文件修订号；上游未给清可退回 | 制图 |
| 可再编辑 | PDF 回传时声明下游能否改回 Word/PPT | 文档册 |
| 来源可核 | 数字/引用能指向原表、原文或用户提供材料；禁止捏造 | 全组 |
| 不外发 | 未用户明确「发送」前，不邮件/聊天外发 | 全组 |

### 版本命名（建议）

```
<主题>-<角色>-v<主.次>-YYYYMMDD.<ext>
例：季度汇报-幻灯-v0.2-20261020.pptx
    台账-表格-v1.0-20261020.xlsx
```

- `v0.x` = 草稿/未定稿；`v1.0+` = 已定稿可进下游
- 大改升主版本；仅错字/样式微调升次版本

## 3. 上下游交接矩阵

箭头 = 交付方向。每次交接必须带：**文件 + 版本号 + 验收清单**。

| 从 → 到 | 必须交付 | 验收（下游勾） |
|---|---|---|
| 文稿 → 幻灯 | 可拆页大纲；每页要点；引用原文位置 | 页目的一句说清；无未标来源的数据 |
| 文稿 → 表格 | 待结构化字段/样例行；枚举说明 | 字段无歧义；单位齐全 |
| 文稿 → 文档册 | 定稿 .docx；页眉页脚/页码要求 | 样式稳定；可转 PDF |
| 表格 → 文稿/幻灯 | 表 + 字段说明 + 单位 + 更新时间 + 来源 | 抽查 2～3 个数字能对上源 |
| 表格 → 文档册 | 定稿导出范围（哪些 sheet/行） | 范围与文件名一致 |
| 幻灯 → 文档册 | 定稿 .pptx；页序；备注是否进 PDF | 页序对；备注策略执行 |
| 制图 → 文稿/幻灯 | 导出图 + 图号 + 版本 + 简要图面说明 | 图号可引用；分辨率够投影/打印 |
| 文档册 → 任一上游 | 处理后 PDF；「可否再编辑」声明；合并则版本清单 | 书签/页序；声明与实际一致 |
| 任一方 → 付老师（总验收） | 交付包；未决问题列表 | 用户目标是否覆盖；有无越界开发组职责 |

### 付老师打回话术（固定字段）

```
【打回】<下游角色>
缺口：…
缺文件/版本：…
请补：…
补齐前不要进下一工种。
```

## 4. 各专员自检清单（开工前 / 交付前）

### 文稿
- [ ] 标题层级连续，目录可生成
- [ ] 对外数字有来源或已标「待确认」
- [ ] 若下游是幻灯：已附可拆页大纲

### 幻灯
- [ ] 平台已确认
- [ ] 大纲已拍板（或用户明示「直接做」）
- [ ] 一页一事；备注与导出需求已问清

### 表格
- [ ] 字段说明齐全
- [ ] 无空单位；日期时区若相关已注明（默认 Asia/Shanghai）
- [ ] 禁止填无法核来源的「好看数」

### 文档册
- [ ] 上游已定稿（或用户授权「用当前稿转」）
- [ ] 合并件有版本清单
- [ ] 回传注明可否再编辑

### 制图
- [ ] 尺寸/图层/版本已向用户或上游确认
- [ ] 图号唯一；导出图可供文稿/幻灯引用

## 5. 与开发组交界（只读边界）

| 事项 | 归谁 |
|---|---|
| OpenSpec / AC / tests / 产品拍板 / 架构 / 界面线框 / 实现 | 开发组（乔丹协调） |
| 部门汇报 PPT、会议纪要 Word、台账 Excel、扫描件 PDF、工程图说明 | 办公组（付老师协调） |

遇边界不清：先问用户一句，或付老师 @ 乔丹确认，**不抢做对方闸门步骤**。
